# Security policy

## Reporting vulnerabilities
Report vulnerabilities privately through GitHub private vulnerability reporting at https://github.com/afflom/UORust/security/advisories/new and never in a public issue.

## Response
afflom triages every security report, acknowledges it within 3 business days, and coordinates the fix and disclosure with the reporter.

## Supported versions
Only the latest published release receives security fixes; vulnerabilities are disclosed through a GitHub security advisory after a fixed release ships.
